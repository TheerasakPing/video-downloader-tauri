AVKuy Download Workflow

เอกสารนี้สรุป workflow ที่ระบบใช้เพื่อดาวน์โหลดวิดีโอจาก www2.avkuy.com หลังจากรองรับเว็บนี้ได้แล้วจริงในแอป

เป้าหมาย

  • รองรับ URL หน้าโพสต์ของ www2.avkuy.com
  • auto detect URL จาก clipboard/ช่องกรอก
  • แสดง title และ thumbnail
  • แยกไฟล์ดาวน์โหลดลงโฟลเดอร์ avkuy/
  • ดึง stream จริงจาก player ที่มี Cloudflare/iframe protection

ตัวอย่าง URL ที่ใช้ทดสอบ

  • หน้าโพสต์: https://www2.avkuy.com/avsubthai-adn-750/
  • iframe player: https://av-kuy.com/v/LQ76ROcLox2aZSg?sid=17081&t=hls

ภาพรวม flow

  1. ผู้ใช้วาง URL หน้าโพสต์ www2.avkuy.com
  2. Frontend ตรวจว่า URL เป็นโดเมน avkuy.com หรือ av-kuy.com
  3. Backend เปิดหน้าโพสต์และดึง metadata เบื้องต้น:
    • title
    • thumbnail/poster
    • iframe player URL
  4. ระบบพยายามสแกน player ผ่าน WebView ก่อน
  5. ถ้ายังไม่เจอ stream URL โดยตรง จะ fallback ไปใช้ Chrome detector กับหน้า player
  6. Chrome detector เก็บ cookie ที่จำเป็น โดยเฉพาะ cf_clearance
  7. Backend ใช้ cookie ชุดนั้น fetch HTML ของหน้า player อีกครั้ง
  8. ระบบ unpack packed JavaScript ใน player เพื่อหา config ของ JWPlayer
  9. ดึง stream URL จริงจาก playlist/sources/file
  10. เริ่มดาวน์โหลดไฟล์ตอนต่าง ๆ
  11. ถ้ามีแค่ 1 ตอน ระบบ rename เป็นชื่อเรื่องปลายทาง
  12. บันทึกผลลัพธ์ลงโฟลเดอร์ดาวน์โหลดย่อย avkuy/

รายละเอียด extraction

1. Parse หน้าโพสต์

หน้า www2.avkuy.com ไม่ได้เปิดเผยไฟล์วิดีโอตรง ๆ แต่จะฝัง player ผ่าน iframe

สิ่งที่ต้องดึงจากหน้าโพสต์:

  • ชื่อเรื่อง
  • thumbnail/poster
  • URL ของ iframe player

ตัวอย่าง iframe ที่พบ:

https://av-kuy.com/v/LQ76ROcLox2aZSg?sid=17081&t=hls

2. WebView pass

ระบบเริ่มจาก WebView extraction ก่อน เพราะบางครั้งสามารถเห็น network/player state ได้เลยโดยไม่ต้องใช้ fallback

ถ้า WebView scan ยังไม่พอ:

  • log จะขึ้นลักษณะ AVKuy player scan X/14...
  • จากนั้นระบบจะ fallback ไป Chrome detector

3. Chrome detector + cookie harvesting

หน้า av-kuy.com/v/... มีการป้องกันเพิ่มอีกชั้นหนึ่ง ถ้าเปิดตรง ๆ อาจเห็นเพียงภาพหรือหน้า challenge แทน player จริง

จุดสำคัญคือ:

  • ต้องเก็บ cookie จาก browser context
  • โดยเฉพาะ cf_clearance
  • ใช้ tab.get_cookies() เพื่อให้เก็บ HttpOnly cookie ได้ด้วย

4. Fetch player HTML ด้วย cookie

เมื่อมี cookie แล้ว backend จะร้องขอหน้า player ซ้ำอีกครั้งแบบมี session/cookie เดิม ทำให้ได้ HTML ของ player จริงแทนหน้า block/challenge

5. Unpack packed JS

ในหน้า player จริง config มักถูก pack/minify ไว้ จึงต้อง:

  • หา script ที่มี player config
  • unpack โค้ด
  • อ่านค่าใน JWPlayer config

ค่าที่เราต้องการหลัก ๆ คือ:

  • sources[].file
  • image

ตัวอย่าง stream URL ที่แกะได้จากเคสทดสอบ:

https://cache11224510.kuylive.com/hls/U0FFd2Njdy9yZ283M3JLYjFzS0h0dz09/xfgdYshjhYhj=!sdsHsyG

ขั้นตอนการดาวน์โหลดในแอป

  1. Auto-detect หรือ paste URL หน้าโพสต์
  2. กด load/analyze
  3. ระบบดึง metadata และ stream URL
  4. แสดง title และ thumbnail ใน UI
  5. cache video URL ที่ตรวจพบ
  6. กด download
  7. ดาวน์โหลดเป็นไฟล์ชั่วคราว เช่น ep_001.mp4
  8. ถ้าเปิด auto-merge:
    • ถ้ามีไฟล์เดียว จะ rename เป็นชื่อเรื่อง
    • ถ้ามีหลายไฟล์ จะ merge ผ่าน ffmpeg

โฟลเดอร์ปลายทาง

ระบบแยกไฟล์ AVKuy ลงโฟลเดอร์ย่อย:

<download_dir>/avkuy/

จาก log ที่ทดสอบจริง:

/Volumes/Media/_VDO_download/avkuy/

ตัวอย่าง log ที่ถือว่า flow สำเร็จ

ลำดับสำคัญที่ควรเห็น:

AVKuy player scan 1/14...
...
WebView not enough, falling back to Chrome detector...
Detecting video from: https://av-kuy.com/v/LQ76ROcLox2aZSg?sid=17081&t=hls
Chrome detector found no video on AVKuy player page
Trying AVKuy player HTML extraction...
Found AVKuy stream via player HTML: https://cache11224510.kuylive.com/...
Auto-loaded: [title] (1 episodes)
Cached 1 video URLs
Starting download of 1 episodes...
Episode 1 downloaded
Merged to: /Volumes/Media/_VDO_download/avkuy/[title].mp4

จุดที่ต้องระวัง

  • เปิด iframe URL ตรง ๆ อาจไม่ช่วย เพราะมักเจอแค่ภาพหรือหน้า block
  • ตัวชี้ขาดคือ cookie/session จาก browser context
  • ห้ามพึ่ง DOM extraction อย่างเดียวสำหรับ av-kuy.com
  • ถ้า player เปลี่ยนรูปแบบ packed script หรือ JWPlayer config อาจต้องปรับ parser

สรุปเชิงเทคนิค

workflow ของ AVKuy ที่ใช้จริงคือ:

post page -> extract iframe/meta -> WebView scan -> Chrome cookie harvest -> fetch player HTML -> unpack JWPlayer config -> resolve stream URL -> download -> merge/rename -> save under avkuy/
